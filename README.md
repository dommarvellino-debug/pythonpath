# PythonPath: a 45-day beginner course

A self-contained learning dashboard for starting Python from scratch. It includes a daily roadmap, short lessons, practice prompts, project checkpoints, and locally saved progress.

## Use the course

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Choose a day from the roadmap. Mark it complete when you finish; progress is saved in that browser.
4. Spend about 30–60 minutes a day. Type and run Python code on your computer using Python 3 and a code editor or terminal.

There are no build steps or package dependencies. The course site uses Google Fonts when an internet connection is available and falls back to system fonts otherwise.

## The learning path

- **Week 1:** Python basics, input, numbers, and your first project: a simple calculator.
- **Week 2:** Conditions and loops; build a number guessing game.
- **Week 3:** Functions and modules; build a unit converter.
- **Week 4:** Lists and dictionaries; plan and build a quiz game.
- **Week 5:** Files and JSON; build an expense tracker.
- **Week 6:** Git, tests, code organization, and project review.
- **Days 43–45:** Polish a project, document it, and publish it to GitHub.

The app prompts you to start a project when you complete its weekly checkpoint. Project prompts and code examples are intentionally optional: try your own solution first.

The five mini-apps are a calculator, number guessing game, unit converter, quiz game, and expense tracker. The final project days help you polish and publish one of them.

## Publish this learning site with GitHub Pages

The course dashboard is static HTML, CSS, and JavaScript, so it can be hosted on GitHub Pages:

1. Create a GitHub repository and add these files.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select your default branch and the root folder, then save.
4. Open the Pages URL shown in settings.

Your Python practice projects are different: GitHub stores and showcases their source code, but GitHub Pages does not run Python programs. The course's calculator and other early projects are terminal applications. To make a Python web app run online later, deploy it to a Python-capable host.

## Progress and privacy

Completed days and the selected day are stored in the browser's local storage on your device. They are not sent to a server. Clearing browser storage resets course progress.
